Corrected adapter before acceptance. `--cache` and `--force` cannot be combined; write-only local caching is a distinct always-execute/record mode, not full cache disablement. - Nx 23 uses shared cache storage by default. Per-fixture `cacheDirectory` is needed for isolated cold-state probes. `--skip-nx-cache` does not prime a local cache; the bootstrap must use an empty, explicitly isolated cache with normal execution. A forced bootstrap followed by a normal run cannot automatically be called no-op.
- Receipt/artifact cohort is explicitly labelled: cached checks create a success receipt. That is not a genuinely outputless always-run check. No bespoke scheduler is introduced by the adapters.
- Nift tracked hooks reject an outputless successful lint/typecheck/unit-test with `custom build did not produce the tracked output file`, blocking downstream tracked actions. Direct `nift tasks/lint.f` successfully runs an outputless check. This is a distinction between task scripting and tracked artifact DAG ownership, not a claim that Nift cannot run arbitrary tasks.
- Injected prerequisite failure blocks Nift descendants and permits independent branches. A normal retry reports unfinished build and requires `nift build --repair`; recovery must use that lifecycle rather than hide it with metadata deletion.
- Structured ordering and invalidation declarations express different contracts in Nift and Nx. Their value should be evaluated separately from repeated authoring and autogenerated fixture file counts.
- The initial 1,000-task Turbo feasibility run exceeded a 90-second harness limit; retain it as a rejected timeout pilot. Retry uses a 1,800-second bound. Small local setup/timer probes briefly overlapped feasibility; their times are not official comparisons.
- The first C-supervisor smoke used a relative metric path with a different subprocess cwd and failed before runner launch. Corrected to absolute report paths. No accepted observation comes from that attempt.
- Common full-dirty comparisons mutate every declared task input with caches enabled; each task must actually execute. A separate cache-disabled 20-task execution cohort uses Turbo `--cache=local:` and Nx `--skip-nx-cache`, with Nift forcing the tracked graph. Turbo write-only caching was an early probe mode and is not presented as cache-disabled execution.
- Isolated feature probes verify output restoration: Turbo/Nx restore a deleted output without starting the task; Nift executes that task to recreate it. These mechanisms are not pooled as cache hits.
- Declared environment probe: Turbo `env` and Nx `{env: ...}` invalidate the relevant task after A→B. Nift's runtime environment read alone leaves the tracked task clean and its previous output intact. A wrapper that writes environment values into files is possible authoring policy, but is not credited as native environment invalidation or included in the common cohort.
- Common quantitative fixtures remain single-project workflows; package graph discovery, framework plugins, remote cache and daemon-assisted interactive latency are not certified.
- The independent auditor additionally requires every planned runner/cell/sample and warmup before issuing an accepted summary. A partial or aborted campaign cannot be accepted merely because its retained rows pass.
- An early subset-smoke run reused mutation values from another scenario and hit a cached prerequisite unexpectedly. The exact action oracle rejected it. Final mutation seeds retain the original global cell index, preventing this collision; no rejected timing is pooled.
