# Native Nift authoring models

The measured tracked adapter is generated by `generators/workflow.py`: one reusable action hook, explicit tracking/prerequisites and declared consumed-file sidecars. It uses supported native Nift scheduling, not an adapter scheduler.

`tasks/*.f` shows direct authored procedural tasks, invoked from a generated fixture with prepared prerequisite artifacts using `nift /absolute/path/to/tasks/lint.f` (likewise test/package/release). These scripts intentionally do not implement a dependency scheduler. Direct outputless lint is separately certified; package/release rely on prepared artifacts. No performance claims are made from these examples.
